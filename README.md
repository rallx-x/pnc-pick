# 뉴럴 클라우드 최애픽 (팬메이드)

GitHub Pages에 이 폴더를 그대로 올리면 동작해요.

## 폴더
- `index.html` — 사이트
- `css/style.css` — 화면 모양 (테마 색은 맨 위에)
- `js/config.js` — **나중에 바꿀 것들** (해금 문구·키워드, 제작자 표기, 기본 테마)
- `js/i18n.js` — 4개 언어 문구 (기업 이름은 영어 표기)
- `js/data.js` — 캐릭터 목록 (엑셀에서 만든 것)
- `js/app.js` — 동작
- `assets/portrait` · `assets/campany` · `assets/class` — 이미지
- `assets/font` — Mona12를 웹용으로 줄인 폰트 + 라이선스 (SIL OFL, 이름은 "PNC Pixel"로 바꿔 둠)

## 내 컴퓨터에서 확인할 때
`index.html`을 더블클릭해서 열면 **이미지 저장이 막혀요** (브라우저 보안 때문).
VS Code의 **Live Server**로 열거나, GitHub Pages에 올려서 확인하세요.
